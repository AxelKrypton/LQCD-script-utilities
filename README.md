# A collection of script utilities

In this repository a bunch of scripts have been collected over the years, mainly to support daily work in research at finite temperature lattice QCD.
In a sense, this set of utilities is the ancestor of [BaHaMAS](https://gitlab.itp.uni-frankfurt.de/sciarra/BaHaMAS): some scripts contained here are actually obsolete, since BaHaMAS took over, while some others are still useful and have remained here.

:warning: The quality of the majority of these script (from the code perspective) is rather low and surprising behaviour might occur.
However, all of them have been manually tested in daily tasks and they used to work as expected in reasonable, standard scenarios.
Some scripts have a `--help` command line option, but it is recommended to have a look to the source code and to the comments next to it.
